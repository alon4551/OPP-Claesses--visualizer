# מאייר ומפרש תכנות מונחה עצמים והורשה — C# || Java (OOP & Inheritance Visualizer)
## אלון שרייבמן — מורה פרטי

יישום Web אינטראקטיבי עצמאי (Client-Side) המאפשר לתלמידים לכתוב, לערוך, להריץ ולדבג קוד **C#** או **Java** בנושא **תכנות מונחה עצמים (OOP) והורשה (Inheritance)**, תוך צפייה במודל הזיכרון החזותי של **"בובות רוסיות" (Concentric Russian-Doll Blobs)**, שרשור בנאים (`base` / `super`), הכרעה דינמית בזמן ריצה (Dynamic Dispatch / Polymorphism), בדיקת טיפוסים (`is` / `instanceof`), המרות טיפוסים (Downcasting) ומערכים הטרוגניים.

## 🌐 תמיכה דו-לשונית מלאה: C# ו-Java

המערכת מאפשרת מעבר חלק בלחיצת כפתור אחת בין שתי שפות הלימוד המובילות במדעי המחשב:
- **בורר שפה בכותרת הראשית**: מעבר בין כפתור **C#** (בגוון כחול זוהר) לבין **Java** (בגוון כתום-אדום).
- **סביבת עבודה מותאמת שפה**:
  - בלשוניות הקבצים: `Program.cs` עבור C# לעומת `Main.java` עבור Java. הוספת מחלקה יוצרת קובץ עם הסיומת המתאימה (`.cs` או `.java`).
  - במנוע ההשלמה האוטומטית (IntelliSense): מילות מפתח, תבניות וקטעי קוד (Snippets) ייעודיים לכל שפה (`super`, `extends`, `@Override`, `System.out.println` לעומת `base`, `virtual`, `override`, `Console.WriteLine`).
  - שמירת העדפה: בחירת השפה נשמרת אוטומטית ב-`localStorage` כך שהתלמיד חוזר תמיד לשפה שבחר.

### 📋 השוואת תחביר בין השפות במערכת:
| נושא | C# 🔷 | Java ☕ |
| :--- | :--- | :--- |
| **הגדרת הורשה** | `class B : A` | `class B extends A` |
| **שרשור בנאים** | בכותרת הבנאי: `: base(x, y)` | בגוף הבנאי: `super(x, y);` (או זימון מרומז `super()`) |
| **דריסת פעולות** | `virtual` בבסיס ו-`override` בנגזרת | ברירת מחדל וירטואלית, תמיכה באנוטציית `@Override` |
| **זימון פעולת אב** | `base.Show();` | `super.show();` |
| **הדפסה למסוף** | `Console.WriteLine(...)` | `System.out.println(...)` / `System.out.print(...)` |
| **קובץ ופונקציית כניסה** | `Program.cs` (`class Program { static void Main() }`) | `Main.java` (`public class Main { public static void main(String[] args) }`) |
| **בדיקת טיפוס בזמן ריצה** | `if (obj is C)` | `if (obj instanceof C)` |
| **המרה מפורשת (Downcasting)** | `((C)obj).Show();` | `((C)obj).show();` |
| **טיפוסים בסיסיים** | `int`, `double`, `bool`, `string` | `int`, `double`, `boolean`, `String` |
| **אורך מערך** | `arr.Length` | `arr.length` |

## 🌟 מודל הזיכרון הפדגוגי: בובות רוסיות (Russian-Doll Blobs)

אחד האתגרים הקשים ביותר עבור תלמידי תיכון בהבנת הורשה הוא התפיסה השגויה שמחלקה נגזרת היא "אובייקט נפרד" מהבסיס שלה.
במציאות של ה-Heap, אובייקט של מחלקה נגזרת מכיל בתוכו באופן פיזי ורציף את כל שכבות האבות שלו!

המערכת ממחישה זאת כבובות רוסיות קונצנטריות מקוננות:
- **`[C [B [A]]]`**: הקופסה החיצונית ביותר היא המחלקה הנגזרת `C`.
- בתוכה מוכלת שכבת מחלקת הביניים `B`.
- בתוך `B` מוכלת שכבת מחלקת הבסיס המקורית `A`.
- **רמות כימוס מובחנות**: כל שכבה מציגה את השדות שלה עם אייקון מותאם:
  - `🔒 private` — שדה פרטי (מוסתר לחלוטין משכבות אחרות).
  - `🛡️ protected` — שדה מוגן (זמין לשימוש בכל השכבות הנגזרות).
  - `🌐 public` — שדה ציבורי (פתוח לכל).

## 🗝️ יכולות המערכת והפדגוגיה

### 1. שרשור בנאים מבפנים החוצה (Inward-to-Outward Construction)
- בעת יצירת אובייקט חדש (`new C("אלון", 100, true)`):
  1. תחילה נוצר שלד האובייקט ב-Heap.
  2. בעת ביצוע `base(...)`, הבנאי מטפס עד למחלקת הבסיס `A`.
  3. ליבת הבסיס `A` מאותחלת ומאכלסת את שדותיה ראשונה.
  4. שכבת `B` נבנית ועוטפת אותה.
  5. שכבת `C` חותמת את הבנייה והאובייקט מתייצב ב-Heap.

### 2. הדמיית פולימורפיזם והכרעה דינמית (Dynamic Dispatch)
- כאשר מוגדר משתנה התייחסות מטיפוס בסיס: `A obj = new C(...)` ומופעלת הפעולה `obj.Speak()`:
  - במחסנית (Stack) מוצג הטיפוס המוצהר בזמן הידור: `[A obj]`.
  - חץ SVG אלגנטי מצביע מהמשתנה אל אובייקט ה-Heap שטיפוסו בפועל הוא `[C]`.
  - בעת הקריאה ל-`obj.Speak()`, המערכת מנפישה חיפוש דינמי בשכבות:
    - נבדקת שכבה `C` — נמצא מימוש דרוס (`override`)!
    - השכבה מוארת באפקט הבהוב ירוק חזק (`dispatch-hit`).
    - מופיעה בועית הסבר פדגוגית בעברית המסבירה מדוע הופעלה גרסה זו.

### 3. עורך C# מרובה לשוניות מחלקות (Multi-Class Tabs)
- לשוניות קבצים נפרדות (`Program.cs`, `A.cs`, `B.cs`, `C.cs`, `Employee.cs`...).
- כפתור `➕ מחלקה חדשה` המאפשר לתלמיד להוסיף קובץ מחלקה חדש בלחיצה.
- מנוע השלמה אוטומטית (IntelliSense) המותאם ל-OOP (`base`, `this`, `virtual`, `override`, `protected`, `ctor`).
- חלון תיעוד פדגוגי בעברית לכל מילת מפתח ותבנית.

### 4. דיבאגר Time-Travel אינטראקטיבי
- צעד קדימה (`Step Next`) וצעד אחורה (`Step Prev`).
- נגן אוטומטי עם סליידר מהירות מתכוונן.
- טבלת מעקב משתנים (Variables Watch).
- מחסנית קריאות לפונקציות ולבנאים (Call Stack).
- מסוף פלט בזמן אמת ל-`Console.WriteLine`.

## 📚 ערכת דוגמאות מובנית (Presets)

1. **✨ פרויקט נקי — ברירת מחדל (`clean`: רק `Program.Main` ריק)**:
   - דף חלק ונקי ללא מחלקות מוקדמות, מוכן לכתיבה מיידית.
   - מאפשר לתלמיד ולמורה ליצור מחלקות חדשות באופן חופשי באמצעות כפתור `➕ מחלקה חדשה`.

2. **🔹 שרשרת 3 רמות (`clean_chain`: `A` ➔ `B` ➔ `C` [x, y, z])**:
   - שרשרת הורשה קונצנטרית מוכנה עם שרשור בנאים: `[C (z:30) --> [B (y:20) --> [A (x:10)]]]`.
   - הדגמת פולימורפיזם מלא: הפניה מטיפוס בסיס `A obj = new C(10, 20, 30);`, הכרעה דינמית `obj.Show()`, והמרת טיפוס מפורשת (Downcasting) `((C)obj).Show()` או `(C)obj.show()`.

3. **📜 שרשרת מורחבת (`basic_chain`: `A` ➔ `B` ➔ `C`)**:
   - שרשרת 3 רמות עם מחרוזות, שרשור בנאים מורחב ודריסת `ToString()`.

4. **💼 היררכיית עובדים ומערך הטרוגני (`EmployeeHierarchy`)**:
   - מחלקת בסיס `Employee` ומחלקות נגזרות `Manager` ו-`Developer`.
   - מערך הטרוגני `Employee[] team = new Employee[2];` ולולאת חישוב שכר פולימורפית (39,000 ₪).
